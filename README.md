# 极地裂隙 · Hex Arena

浏览器 2.5D 单线乱斗原型，结合幸存者式自动战斗、交替兵线、海克斯强化与复活点商店。当前为单机版，联机计划见 `NETWORK.md`。

- 经典英雄选择：无极剑圣、寒冰射手、德玛西亚之力、光辉女郎、探险家、蒸汽机器人、祖安花火、堕落天使
- 单线兵线、双方每 9 秒同步交替出兵、自动攻击、经验升级和治疗圣坛
- 从地图中心向阵营后方排列：防御塔 I → 防御塔 II → 水晶 → 两座并列门牙塔 → 核心枢纽 → 复活点
- 蓝方和红方核心后方各有一个发光复活点，英雄死亡后从所属复活点恢复并重新入场
- Q/W/E/R 技能、死亡复活；升级后点击右下角按钮打开海克斯强化三选一
- 银/金/棱彩强化会实际改变伤害、范围、护盾、冷却、结构伤害和特殊被动
- 复活点商店可购买药水、装备和破城道具；只有在复活点附近且连续 5 秒未受伤时开放，升级或死亡只会排队等待开放
- 固定朝向的等距镜头跟随角色移动；小地图显示英雄、小兵、建筑位置，不显示血量
- 英雄、小兵、建筑的头顶血条始终为水平矩形，不随模型旋转和受击缩放
- 本地 GLB 英雄模型、近战/远程/法师攻击表现、不同类型的小兵模型

## 建筑与炮塔规则

双方沿地图中心镜像布置，各建筑距中心依次为 32、60、76、88、100；复活点距中心 110。两座门牙塔位于同一纵向位置，横向偏移 ±4。

必须按前置顺序摧毁建筑。水晶不攻击，被摧毁后敌方召唤超级兵。两座门牙塔同时解锁，全部摧毁后才能伤害核心。

所有炮塔攻击半径为 **12**；前两座防御塔间距 **28**，两个攻击圆之间保留 **4** 个地图单位的空隙。目标离开所属炮塔射程后，炮塔导弹消失，不会追踪到全图。

炮塔每 **1.5 秒**发射一次，每次锁定一个敌方英雄或小兵。目标存活且在射程内时保持锁定；死亡或离开射程后重新选择。若射程内的敌方英雄伤害本阵营英雄，炮塔立即转火该攻击者，普通攻击、技能及弹射命中均适用。换目标不重置冷却，小兵伤害不触发英雄仇恨。

连续命中同一英雄时加热：首发 85，随后每次命中增加 25% 基础伤害，即 106.25、127.5、148.75……。小兵始终承受基础炮击伤害。换目标、目标死亡或离开射程后清空加热；未命中的炮弹不增加层数。各炮塔独立计算。

建筑具有实体碰撞，小兵和 AI 英雄绕行，玩家移动与位移技能也不能穿过存活建筑。炮塔摧毁时播放 `Destroyed`，结束后仅保留原模型的 `Rubble` 底座；残骸没有血条、攻击或碰撞，不再阻挡推进。

双方同类小兵和炮塔使用相同生命、伤害、射程、攻速和移动速度。第一波为 3 个近战兵 + 2 个远程兵，第二波为 2 个近战兵 + 2 个远程兵 + 1 个炮车兵，之后按奇偶波循环；每波每方固定 5 个单位，相邻波次间隔 9 秒。开局已有第一波，9 秒后才出第二波，暂停期间不计时。自动出兵统一到这套规则，波次之间不再插入额外潮群。

超级兵由摧毁敌方 Inhibitor 解锁，从该阵营下一波起，用 2 个超级兵替换 2 个近战兵。强化后的奇数波为 1 近战 + 2 超级 + 2 远程，偶数波为 2 超级 + 2 远程 + 1 炮车；另一阵营按自己的解锁状态出兵。既有小兵不追溯替换。玩家装备和海克斯伤害加成只作用于玩家本人，不会改变友方小兵或炮塔的伤害。

远程兵攻击距离为 7，炮车为 8；近战兵为 2.3，超级兵为 2.8。所有小兵进入攻击距离后固定目标并停止前进，攻击冷却期间也保持原地。只有目标死亡或超出攻击距离才解锁目标，重新寻找目标或恢复行进；不会因为其他敌人靠近而频繁切换。

## 模型、动画与场景

英雄、小兵和建筑使用本地 GLB 内嵌贴图。每个单位拥有独立骨骼与动画混合器，按行为播放待机、移动、攻击、技能和死亡；死亡动作播完才隐藏英雄或移除小兵，复活恢复待机。炮塔素材没有独立 Attack 片段，攻击以炮弹和发射特效表现，并绑定 State2、State3 受损外观与 Destroyed 残骸网格。

本轮比例调整：英雄缩小 25%，小兵缩小 15%，作战建筑放大 15%。血条高度和碰撞体积同步调整，泉水向后移至 ±110，为放大的 Nexus 留出间隔。比例集中在 `game3d.js` 的 `sceneScale` 中。

英雄与双方小兵的模型正面统一为 +Z，移动及攻击朝向直接沿用单位转向，移除多余的 180° 模型旋转。

按鸟瞰参考搭建镜像单线深渊石桥：两端基地、兽首雕像、铁链、侧桥、断面、旗帜、火盆、冰崖和雪点。临近镜头的基地围墙采用低墙，避免挡住泉水和 Nexus。商店使用 Howling Abyss 商店与商人模型，开关商店时播放对应动画。复活平台为程序化光圈，配有导出的泉水炮塔；并非完整原版泉水场景。未找到可直接导出的整张地图，桥面和地形仍由程序化几何与贴图拼搭。

## 启动与检查

**给 Windows 10 / 11 用户：完整解压发布 ZIP，双击 `START-GAME.cmd`，在自动打开的 Edge / Chrome 中选择英雄。** 无需安装 Node.js、Python或以管理员身份运行；游玩期间保留启动窗口，退出后关闭即可。启动器只监听本机，默认使用 8002 端口，被占用时自动选择可用端口，实际地址显示在启动窗口。

模型、头像、技能图标和特效贴图全部随包提供，运行时不依赖外部 CDN，支持断网游玩；电脑和浏览器仍需支持 WebGL。完整步骤见 `PLAY-README.txt`。分享时发送整个 ZIP，不能只发 `index.html`。直接双击 HTML 会显示启动步骤，避免模块被 `file://` 拦截后出现空白英雄列表。

macOS / Linux 用户可通过已部署的 HTTPS 网页链接游玩，或自行启动 HTTP 静态服务器；Windows 启动器不适用于其他系统。目前仍为单机版。开发目录也保留 Node 启动方式：

```powershell
cd .code
node dev-server.cjs
```

打开 <http://127.0.0.1:8001/>。项目根目录运行 `node .code/package-release.cjs` 更新 `release/`；目录包括网站文件、完整素材、Windows 启动器和说明。可整体上传到 GitHub Pages 仓库根目录，保留 `models/` 和 `assets/` 子目录结构。`127.0.0.1` 只供本机使用，在线分享应使用部署后的 HTTPS 地址。

发布验证运行 `node .code/check-portable.cjs`，从 ZIP 解压到包含中文、空格的不同目录，用 Windows 自带 PowerShell 启动，禁用浏览器外部网络请求，检查文件直开提示、8 名英雄选择和模型、图标、特效加载，以及端口占用、静态网站子路径部署和启动错误提示。

回归检查在项目根目录运行：`node .code/check-combat.cjs`、`node .code/check-navigation.cjs`、`node .code/check-balance.cjs`。浏览器检查 `check-models.cjs`、`check-facing.cjs`、`check-waves-browser.cjs`、`probe-combat.cjs` 需要 Playwright 和 Edge；默认访问 8001，也可将测试 URL 作为第一个参数。覆盖骨骼独立性、行为动画、死亡复活、双方炮塔底座、血条、30 条全图绕行路线、射程与仇恨加热、阵营属性一致性和小兵目标锁定。朝向检查覆盖 8 名英雄的四向移动和攻击，并输出双方全部小兵的方向参考截图。

## 素材来源

- 英雄模型：从 <https://modelviewer.lol/?lang=zh-CN> 导出，保存在 `models/`。
- 小兵模型：双方近战、远程、炮车和超级兵，来自 modelviewer.lol 的 extras；`models/minions/sources.json` 记录具体来源和动画。
- 建筑和场景模型：Turret、Inhibitor、Nexus、Brawl Fountain Turret、Howling Abyss 商店/商人/兽首/铁链/侧桥/断面/旗帜；`models/world/sources.json` 记录来源和动画。未采用导出结果不完整的 healthrelic 和 chaosturretshrine。
- 英雄头像、技能图标：Riot Games Data Dragon 14.24.1 公开资源，已下载至 `assets/`，具体原始地址见 `assets/sources.json`。`download-ui-assets.cjs` 从官方英雄数据读取正确图片名称后下载。
- 雪花、火花粒子贴图：Three.js examples 的 `textures/sprites/`，已下载至 `assets/effects/`。
- 场景石砖、雪岸、冰崖、火盆及备用角色模型：本项目程序化生成。
- 渲染：Three.js、GLTFLoader、BufferGeometryUtils 和 SkeletonUtils。

原型没有解包或复制本地英雄联盟安装目录中的 WAD 文件；旧 2D 版保存在开发目录的 `index-2d.html`。
