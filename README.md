# 极地裂隙 · Hex Arena

这是一个浏览器 2.5D 原型，用 Three.js 的正交等距镜头做了原创的单线乱斗与幸存者式潮群玩法：

- 经典英雄选择：无极剑圣、寒冰射手、德玛西亚之力、光辉女郎、探险家、蒸汽机器人、祖安花火、堕落天使
- 单线兵线、持续敌方潮群、自动攻击、经验升级和治疗圣坛
- 完整结构链：2 座外侧防御塔、1 座高地抑制器、2 座门牙塔、1 个核心枢纽
- 蓝方和红方核心后方各有一个发光复活点，英雄死亡后从所属复活点恢复并重新入场
- Q/W/E/R 技能、死亡复活，以及升级时暂停战斗的海克斯强化三选一
- 银/金/棱彩强化会实际改变伤害、范围、护盾、冷却、结构伤害和特殊被动
- 场景、冰面、雪岸、冰晶和粒子使用程序化材质；英雄头像来自 Riot Data Dragon

你提供的安装目录中确实有海克斯大乱斗对应的 `Game/DATA/FINAL/Maps/Shipping/Map453.wad.client`，但它是专用二进制 WAD 包（约 479 MB），当前原型没有把它复制或解包进项目；地图节奏和结构链按单线模式自行复刻。原来的 2D 像素版保存在 `index-2d.html`。

直接双击 `index.html` 即可游玩；也可以在 `.code` 目录启动静态服务器：

```powershell
python -m http.server 8000
```

然后打开 <http://localhost:8000>。
