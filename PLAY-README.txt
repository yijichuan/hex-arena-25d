极地裂隙 · Hex Arena — 启动与分享说明

Windows 10 / 11 本地游玩
1. 将 ZIP 发布包完整解压到一个文件夹。不要在 ZIP 预览窗口内直接运行。
2. 双击 START-GAME.cmd，浏览器会自动打开游戏；建议使用新版 Edge 或 Chrome。
3. 选择英雄开始游戏。游玩期间保持启动窗口开启，退出后关闭该窗口即可。

无需安装 Node.js、Python，也不需要管理员权限。
英雄、兵种、建筑模型、头像、技能图标和特效贴图均已包含，解压后可离线游玩。
本机需要支持 WebGL 的显卡与浏览器；目前操作面向键盘、鼠标。

分享给朋友
- 发送完整 ZIP，接收者按上述步骤解压、双击即可。
- 不要只发送 index.html，也不要拆开 models/、assets/ 等目录。
- 发布包可以移动或改名，启动器会使用自己所在的目录。
- 当前游戏是单机版本，分享发布包不会开启联机。

打不开时
- index.html 出现“请用启动器打开游戏”属于正常提示，请改用 START-GAME.cmd。
- 浏览器没有自动打开：复制启动窗口中的 GAME_URL 地址到 Edge 或 Chrome。
- 默认 8002 端口被占用：启动器会自动选择其他可用端口，以窗口显示的地址为准。
- 出现 WebGL 错误：更新浏览器并开启图形加速，更新显卡驱动后重试。
- 缺少文件：重新完整解压，不要单独移动启动器或网页。

网页链接分享与其他系统
可将本文件夹的网页、脚本、models/、assets/ 整体发布到 GitHub Pages 等静态网站，
接收者通过 HTTPS 链接在支持 WebGL 的桌面浏览器中打开，无需本地启动器。
START-GAME.cmd 仅适用于 Windows；macOS / Linux 请通过网页链接游玩，
或使用自己的 HTTP 静态服务器打开此目录。不要直接通过 file:// 打开网页。
本机 127.0.0.1 地址不能作为互联网分享链接。
